# Rucking Fitness News — Issue 01

**Issue title:** Neil Neil's Mystic Peel  
**Format:** Interactive palm reader / web newsletter  
**Suggested live domain:** `news.ruckingfitness.co.uk`

## Deploy to Netlify

This is a static site. No build command is required.

- Publish directory: `.`
- Entry page: `index.html`

You can either:
1. Upload this folder/repository to GitHub and connect the repository to Netlify, or
2. Drag the site folder into Netlify for a manual deploy.

## Files

- `index.html` — the complete interactive Issue 01 page
- `assets/palm-reader.jpg` — palm reader artwork
- `netlify.toml` — Netlify static-site settings
